# Agent francophone

Ce dépôt définit un agent Claude Code personnalisé qui **répond toujours en français**.

## Utilisation

L'agent est défini dans [`.claude/agents/francais.md`](.claude/agents/francais.md).

Pour l'utiliser dans Claude Code :

```
> demande à l'agent francais de ...
```

Ou lance-le explicitement en le désignant par son nom : `francais`.

Quelle que soit la langue de ta question, l'agent te répondra en français.
